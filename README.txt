ABOUT MY WEBSITE
For this assignment I made an information website for SET Days 2026, which
will be held on December 2-4, 2026 at National University Fairview in
Quezon City. I wanted the site to feel like a real school event page, so
the title is "SET Days 2026" and the tagline I came up with is
"Rise. Compete. Unite."

SET Days is about programs competing against each other in sports, esports
and other activities, so I wanted visitors to feel the excitement and
school spirit as soon as they open the page.


MY CONCEPT AND THEME
I went with a tournament or championship feel, but still formal enough for
a school website. For the colors I used National University's navy blue and
gold, since those are the school colors. I picked them to match how NU's
own sites look. The page is also responsive, so it still works on a phone.


WHAT'S IN THE PAGE
The site has one page (index.html) with these sections:
- Home
- About SET Days
- Event Activities
- Three-Day Schedule
- Venue and Event Guide
- Featured Highlights
- Participation Guidelines
- Contact and footer
The navigation links at the top jump to each section using HTML ids. The
campus photo in the venue section is an image map, so clicking parts of the
photo takes you to the Activities, Schedule, Featured and How to Join
sections.

HTML elements I used: headings, paragraphs, links (internal, external and
mailto), images, an image map, a table, ordered, unordered and description
lists, horizontal rules, line breaks, preformatted text, div and span.


FILES IN THE ZIP
- index.html
- css/style.css
- images/ (the two campus pictures and the NU logo)
- README.txt
I did not use JavaScript, so the js folder is not included.


IMPORTANT NOTE
All the event details on the website (schedule, venues, speaker, committee
names, deadline and email address) are made up for this assignment. They
are not official NU announcements. I also put a note about this at the
bottom of the website.
